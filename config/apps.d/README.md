# Community App Definitions

Place per-app JSON files here. Each file defines a single app entry
that will be merged into `newcomers` at startup.

**Usage:**
```bash
m4b app add          # Interactive wizard — creates a file here
```

Or create files manually following the schema in `docs/app-schema.json`.

**File naming:** `<APPNAME>.json` (e.g. `MYAPP.json`)

**Example:** See `docs/APP_SCHEMA.md` for a minimal template.
